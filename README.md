## Descripción

Este repositorio forma parte de mi formación en ciberseguridad y documenta el proceso de resolución de distintos laboratorios y máquinas CTF de plataformas como:

- Hack The Box
- TryHackMe
- VulnHub
- [INE: Penetration testing student](ejpt/README.md)
- Entornos propios

El objetivo es demostrar metodología, capacidad de enumeración, explotación y post-explotación, además de mantener un registro técnico de aprendizaje continuo.

## Objetivos

- Practicar técnicas de pentesting
- Mejorar habilidades de enumeración y explotación
- Documentar procesos reales de resolución
- Compartir conocimiento y aprendizaje


## Metodología

La metodología habitual seguida en los laboratorios incluye:

1. Reconocimiento
2. Enumeración
3. Análisis de vulnerabilidades
4. Explotación
5. Post-explotación
6. Documentación
